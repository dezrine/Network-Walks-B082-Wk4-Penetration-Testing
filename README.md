## 📌 Project Module Overview

This **Week 4 – Network Walks Penetration Testing Project** focuses on conducting a controlled **black-box penetration test** against **Mediroza General Hospital**.

The engagement covers reconnaissance, identifying exposed entry points, analysing authentication and application behaviour, retrieving confidential PDF lab reports, analysing and recovering encrypted files, investigating critical data exposure, and documenting the results in a professional penetration-testing report.

The engagement is authorised for educational purposes and is limited to the agreed target and scope.

## 🎯 Project Milestones

| Milestone                       | Objective                                                                                           |
| :------------------------------ | :-------------------------------------------------------------------------------------------------- |
| **M1 — Initial Access**         | Identify an attack path and retrieve 3 confidential patient PDF lab reports                         |
| **M2 — Data Extraction**        | Analyse and recover the contents of all 3 encrypted files                                           |
| **M3 — Critical Data Exposure** | Investigate the retrieved material and identify exposed employee salary and shareholder information |
| **M4 — Pentest Report**         | Produce a detailed professional penetration-testing report                                          |

The project brief defines these four milestones and their corresponding deliverables.

## ⚠️ Scope & Rules

Testing is restricted to the authorised target domain. The engagement rules prohibit social engineering, denial-of-service testing, and testing outside the agreed scope.

> **⚠️ Educational Use Only**

> This project is conducted in a controlled environment for educational purposes. Security-testing techniques must never be applied to systems without explicit written permission from the owner.
